# Raphael — GunLol Discord Sync Bot

Phiên bản bot tối giản chuyên dùng cho hệ thống **guns.lol Clone (`D:\GunLol`)**:
- Đọc trạng thái Online / Idle / DND / Spotify / Game trong server Discord riêng.
- Cung cấp slash command `/bio` và `/syncstatus` trong server.
- Mở API nhỏ (`/presence/{user_id}`, `/members`, `/health`) ở cổng `4001` (hoặc biến môi trường `PORT`) nếu triển khai tách rời với web.

## Chạy cục bộ
Nhấp đúp **`run-local.cmd`** ở thư mục gốc.
